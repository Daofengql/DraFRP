# Security policy

[English](SECURITY.en.md) | [简体中文](SECURITY.md)

Please report suspected vulnerabilities privately. Use GitHub Security
Advisories for this repository when the private reporting option is available.
Do not publish exploit details in Issues or Discussions before a fix is
available.

Include the affected version or commit, relevant configuration, impact, and
steps to reproduce. Remove real credentials, certificates, customer data, and
publicly reachable hostnames unless they are essential to reproduce the issue.

The project is under active development. Supported release versions and fix
timelines are not yet defined.
